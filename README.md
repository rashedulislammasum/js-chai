# js-chai

A simple JavaScript playground project.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine

### Running

Run the script with Node:
Added a new line

```bash
node test.js
```

Expected output:

```
Hello, World!
```

## Project Structure

```
js-chai/
├── test.js      # Entry script
└── README.md    # Project documentation
```
